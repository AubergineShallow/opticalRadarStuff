FILE: server_main.py (Server - Multi-Cluster Phase)
PURPOSE: Main server orchestrator that manages multiple independent domains/clusters.
EXECUTION: Run as module (python -m server.server_main) or use run_server.py launcher.

================================================================================
WHAT THIS FILE DOES
================================================================================
Orchestrates the entire optical radar backend. Instead of a single tracking volume,
the server now routes incoming telemetry to specific, isolated tracking domains
(clusters) using the ClusterManager.

--------------------------------------------------------------------------------
COMPONENTS IT USES
--------------------------------------------------------------------------------
1. NETWORK: UDPServer (Ingest), WebSocketBroadcaster (Egress/Commands)
2. PROCESSING: ClusterManager (Domain routing and tracker instantiation)
3. SECURITY: Authenticator
4. MONITORING/VALIDATION: NodeHealthMonitor, GroundTruthValidator, StructuredLogger
5. VISUALIZATION: Headless mode support, generic visualizer fallback.

--------------------------------------------------------------------------------
STARTUP SEQUENCE
--------------------------------------------------------------------------------
1. LOAD CONFIG & SECURITY
   - Load config.yaml, init StructuredLogger.
   - Init Authenticator if enabled in environment/config.

2. INIT SUBSYSTEMS
   - Create UDPServer and WebSocketBroadcaster
   - Register WS Command Handlers ('CREATE_CLUSTER', 'ASSIGN_NODE')
   - Create ClusterManager
   - Create NodeHealthMonitor and GroundTruthValidator

3. START SERVERS & LOOP
   - UDP and WS servers start background threads.
   - Main loop runs at target FPS.

--------------------------------------------------------------------------------
MAIN LOOP
--------------------------------------------------------------------------------
EVERY FRAME:

1. INGEST & ROUTE PACKETS
   - For packet in UDP queue:
       - Verify signature (Authenticator).
       - IF GT Packet: Send to GroundTruthValidator.
       - IF Announce Packet: Auto-assign unassigned nodes to 'DEFAULT'.
       - IF Telemetry:
           - Update NodeHealthMonitor.
           - Ask ClusterManager for the node's assigned cluster.
           - Build Rays via the cluster's RayBuilder.
           - Add to the cluster's VoxelGrid.

2. TICK CLUSTERS
   - For every active cluster in ClusterManager:
       - Decay VoxelGrid.
       - Extract detections (hot voxels).
       - Update the cluster's Tracker.
       - Extract tracks.
       - Evaluate Tracks against Ground Truth (if available).
       - Broadcast isolated track updates via WebSocket to subscribers of this cluster.

3. BROADCAST SYSTEM STATUS
   - Calculate FPS.
   - Every ~1s, build cluster topology map (assigned nodes, effective volume).
   - Broadcast status (health, clusters, pending nodes) via WebSocket.
