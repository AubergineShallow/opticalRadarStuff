================================================================================
NEW SUBSYSTEMS OVERVIEW
================================================================================

1. TRACKING SUBSYSTEM (4 modules)
   - Converts voxel detections into persistent tracked objects
   - Maintains object identity across frames
   - Estimates velocity and trajectory

2. MONITORING SUBSYSTEM (3 modules)
   - Tracks camera health and connectivity
   - Collects system performance metrics
   - Provides structured logging for debugging

3. VALIDATION SUBSYSTEM (2 modules)
   - Validates calibration is improving, not degrading
   - Compares detections against ground truth references
   - Quality scoring and alerts

4. SECURITY SUBSYSTEM (2 modules)
   - HMAC-based message authentication
   - Shared secret management
   - Prevents spoofed telemetry packets

5. CONFIGURATION SYSTEM (1 module)
   - Centralized config file management
   - Environment variable support
   - Runtime reconfiguration capability

================================================================================
BACKWARD COMPATIBILITY
================================================================================

- Protocol changes are VERSION=3 (VERSION=2 still supported)
- Tracking is optional (can run with raw detections)
- Security can be disabled for testing
- Monitoring is non-invasive (just observers)
- Old cameras can still connect (receive warnings)

================================================================================
DEPLOYMENT NOTES
================================================================================

MINIMAL DEPLOYMENT (Testing):
  - Use existing modules + config system
  - No security, no tracking
  - Monitoring optional

PRODUCTION DEPLOYMENT:
  - All subsystems enabled
  - Security required
  - Tracking required
  - Full monitoring/logging
